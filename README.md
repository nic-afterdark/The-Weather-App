# 🌦️ The Weather App

A simple React-based weather application that allows users to search for any city and view the current weather, temperature, sky conditions, and more using the OpenWeatherMap API.

---

## 🚀 Features

- 🔍 Search weather by city name
- 🌡️ Displays current temperature in Celsius
- 🌤️ Shows sky conditions like "Clear", "Cloudy", "Rain"
- 🗓️ Displays current date
- 🌍 Shows country code of the searched city
- ⚠️ Handles invalid/mistyped city names with error messages

---

## 🛠️ Technologies Used

- React.js
- JavaScript (ES6)
- OpenWeatherMap API
- HTML & CSS
